# Hero Adventure — Leveling Window Report

Per-leg permutation window for each stat: base class stat, plus this leg's
level-up choice (+5 or +0), plus this leg's obtainable loot (every quality
tier that can drop that leg, best and worst roll, on the stat's matching
item category and the wildcard "accessories" slot). Relics / super-monster
loot are excluded. Each leg is an independent snapshot, not a carry-over
from previous legs.

Note: `medical` has no dedicated loot category - its only equipment source
is a lucky "accessories" roll (bonus +0).
